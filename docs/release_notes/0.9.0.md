First archived release of TSARM, the code behind the results obtained so far.

**Pipeline**
- Ingestion: N-Triples/Turtle (Spark and RDFLib), DBpedia releases, Wikidata P31/P279 extraction with rank and
  valid-time qualifiers (P580/P582/P585).
- Windowing: snapshot windows (width/step) and calendar valid-time windows.
- Semantic items: fact items, or class items with superclass closure (SPARQL property path via RDFLib or Spark
  semi-naive iteration, optional depth limit) and taxonomic-rule pruning.
- Mining: per-window FP-Growth, or a length-bounded generalized miner with ancestor pruning; exact recount of
  every candidate in every window.
- Metrics: temporal support, confidence drift (mean first difference), volatility, rule persistence score,
  lifecycle classes (stable, emerging, decaying, transient, intermittent), rule trajectory embeddings.

**Evaluation**
- E1 core scaling and E2 cluster scaling (Spark standalone scripts for Oracle Cloud and Google Cloud).
- E3 rule quality (planted ground truth; annotation kit for real data) and E4 temporal sensitivity (planted events;
  event proposer for real data).
- E5 runtime comparison with AMIE+ and RDFRules (paired statistics).

Tested on PySpark 4.0.3 and 3.5.3 (Java 17).
